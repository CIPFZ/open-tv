# 电视应用功能优先级

## 设计原则

这个产品首先是一台“网络电视机”，其次才是播放列表工具。主界面不应该像内容平台或媒体管理器，而应该让用户打开后马上看到画面，并且可以用最少的操作换台、调节音量和退出全屏。

## 一级功能：观看时必须直接可用

这些功能必须在主播放界面完成，不依赖复杂菜单：

| 功能 | 交互 | 设计要求 |
| --- | --- | --- |
| 播放画面 | 启动后自动播放上次频道或第一频道 | 视频占据绝大部分窗口，控制层默认隐藏 |
| 上一台 / 下一台 | 键盘 `↑` / `↓`、遥控器频道键、左上角频道信息 | 切台后更新频道编号和频道名，切台失败可继续上下切换 |
| 音量调节 | 键盘 `←` / `→` 或 `+` / `-`、鼠标控制条 | 音量条和静音状态只在操作时出现 |
| 静音 | `M` 键、播放器静音按钮 | 不改变频道，不遮挡画面 |
| 播放 / 暂停 | `Space` 或播放按钮 | 直播源不支持暂停时给出轻提示，不阻塞播放 |
| 全屏 / 退出全屏 | `F` 或双击画面、`Esc` 退出 | 全屏时保留换台和音量快捷键 |
| 播放状态 | 加载中、播放中、源失效、重试 | 错误覆盖层简短明确，提供重试和换台 |

## 二级功能：辅助观看，不抢主界面

这些功能通过一个短暂的 OSD（屏幕控制层）或侧边抽屉访问：

- 快速频道条：显示相邻频道和频道号，按上下键切换。
- 频道列表：按播放列表分组浏览、搜索频道、直接跳转。
- 节目单：查看当前频道和接下来节目；没有 EPG 时不显示空面板。
- 播放列表切换：在多个用户来源之间切换。
- 最近观看：保留最近几个频道，作为快速返回入口；不做独立的“收藏”系统。

## 三级功能：管理和设置

这些功能放在独立的设置页或管理抽屉，不出现在主播放区：

- 添加、删除、刷新远程 M3U/M3U8 来源。
- 导入本地 M3U 文件。
- 默认启动频道和默认播放列表。
- 播放器后端选择（浏览器 HLS / 原生播放器，后续再加入 mpv）。
- 网络超时、重试次数、字幕和画面比例。
- 键盘快捷键说明、日志导出、关于和许可证。

## 明确移除或延后

- 不设置独立的“我的收藏”主导航。
- 不在首页展示大量频道卡片、推荐内容或节目海报。
- 不把 Playlist、Settings 放在与播放同等显眼的一级区域。
- 不在第一版加入社交、账号、订阅、推荐算法和内容运营。

## 主界面布局基线

```text
┌──────────────────────────────────────────────────────┐
│                    视频播放画面                      │
│  [频道名 / LIVE]                    [加载 / 错误提示] │
│                                                      │
│  ──────── 操作时出现：音量 · 频道 · 全屏 · 设置 ──── │
└──────────────────────────────────────────────────────┘
     ↑/↓ 换台      ←/→ 音量      M 静音      F 全屏

  次级入口：频道列表 / 播放列表 / 节目单 / 设置
```

主播放界面只保留必要状态和操作；频道列表、播放列表和设置都以抽屉、弹层或独立页面承载。
