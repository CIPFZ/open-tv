- [x] 支持 M3U 解析、搜索、分组、退出前频道恢复和 HLS 播放

- [x] 引入 Vite/TypeScript 模块化构建和基本测试
- [x] 完善基础错误状态、加载超时和手动播放重试
- [x] 加入播放列表管理抽屉、来源删除和切换
- [ ] 节目单：XMLTV 解析和匹配能力已预留；当前 PC 版本暂不开放设置入口，待稳定授权来源后再恢复展示

- [ ] 增加更完整的可访问性和移动端适配

## P2：PC 桌面端（首个正式应用，进行中）

- [x] 加入主进程、预加载脚本和播放服务的边界骨架

- [ ] 完成三平台实际安装包、签名和发布验收

- [x] 增加快捷键、窗口全屏、应用音量和退出前频道恢复
- [ ] 增加系统音量控制
- [x] 日志脱敏、配置迁移和原生文件选择

## P3：Android 与 Android TV

- [x] 抽离跨平台的数据模型、M3U/XMLTV 解析和来源配置格式
- [x] 建立 Android/Android TV 共享模型和遥控器输入语义骨架
- [ ] Android：触屏浏览、后台恢复、Media3 完整播放和配置读写（当前已有 Compose/Media3 TV-first 入口、Activity 生命周期暂停/恢复、v1 JSON 存储、配置导入/导出、HTTPS 来源加载、XMLTV 加载与当前/下一节目显示、本地 M3U/M3U8 文件选择、远程来源表单、来源刷新/启停/删除、频道侧栏和与桌面一致的居中设置弹层）
- [ ] Android TV：焦点导航、遥控器、Media3、电视启动器和安装包
- [ ] 统一频道分组和播放列表迁移策略；如重新开放 EPG，再增加节目单迁移

## P4：稳定性与发布

- [ ] 频道源健康指标和手动下架机制
- [ ] 隐私说明、开源许可证和第三方来源说明
- [ ] 崩溃日志（默认关闭内容和 URL 采集）
- [ ] 发布前逐条审核内置来源的授权与地域限制
- [ ] 打包、自动更新和版本回滚策略

## 当前路线决定

首个正式目标已经确定为 PC 桌面端。Android 和 Android TV 作为后续客户端，共享频道、播放列表、上次频道、播放偏好和可选 EPG 的数据模型，但分别适配触屏与遥控器交互。
