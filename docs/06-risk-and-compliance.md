# 风险与合规边界

## 1. 直播源风险

公开 URL 不等于长期可用，也不等于已经获得转播授权。源可能发生过期、地区限制、Referer/User-Agent 要求、CORS 限制或瞬时拥塞。产品需把“来源状态”和“播放失败”当作常态处理。

## 2. 版权与发布边界

[iptv-org/iptv 的说明](https://github.com/iptv-org/iptv)指出其仓库保存的是用户提交的公开视频流 URL，不保存视频文件；同时也说明维护者无法控制链接目标。这个说明不能替代本项目在目标市场的法律审查。

因此本项目采取以下规则：

- 开发阶段可以用公开列表验证播放器，但正式产品不默认承诺任何频道的长期可用或观看权。
- 内置源只保留经过来源记录、可说明用途的公开或授权源；来源不清楚就不内置。
- PC 端来源、节目单和媒体地址默认要求 HTTPS，拒绝在 URL 中携带账号或密码。
- 提供用户自行添加和删除来源的能力，保留来源 URL、更新时间和免责声明。
- 不提供绕过 DRM、登录、付费、地区限制或反爬验证的功能。
- 收到权利人下架通知后，停止内置来源并记录处理结果。

## 3. 隐私

MVP 不要求账号，收藏和最近来源保存在本地。默认不上传观看历史、频道 URL 或播放内容。若未来增加诊断上报，应先脱敏，并允许用户关闭。

## 4. 发布前检查

- 核对每个内置频道的来源、授权范围和地区限制。
- 核对依赖库许可证、Logo 使用权限和第三方项目归属。
- 检查日志中没有播放列表凭据、Token 或完整私有 URL。
- 对 URL 导入、Logo、XMLTV 和播放器错误做安全测试。
- 在中国大陆及其他目标地区分别确认适用的内容和网络合规要求。
